# Md. Hasanuzzaman — Personal Portfolio

Futuristic personal portfolio website of **Md. Hasanuzzaman**, Head of the Department of Computer Science & Engineering (CSE), Canadian University of Bangladesh.

**Live site:** https://sojolmahfuz.github.io/md-hasanuzzaman-portfolio/

## Sections
- Hero with animated network background
- About & terminal profile
- Research Interests — Computer Networking, Cyber Security, Network Security, Data Security
- Education timeline — Ph.D. (in progress), M.Sc. in IT (University of Waterloo), B.Sc. (Khulna University)
- Department leadership
- Publications & Google Scholar metrics
- Contact

## Admin Console
- **Path:** `/admin/` (or accessible via the discreet "Admin" link in the footer)
- Secure cryptographic authentication gate
- Dynamic content management for Profile, Research, Education, Publications, Scholar metrics, and Leadership
- 1-click cloud sync directly to GitHub Pages
- Local inbox for contact form submissions

## Tech
Pure HTML5, CSS3, vanilla JavaScript, and GitHub REST API integration — no external build tools or backend servers required.
